# Pantry App

Pantry is an native Android app that tracks whats inside a users pantry.

## Features
- Pantry Tracking
- Recipe Matching
- Seeded Ingredients and Recipies
- Settings Menu 
    - Resets Database


## Requirments
- Android Studio 2024.2 or newer

## Getting Started

1. Clone the repo
```bash
   git clone https://github.com/UNITSEV3N/pantry.git
   cd pantry
```

2. Open in Android Studio
3. Sync Gradel
4. Select Emulation Device
5. Run
